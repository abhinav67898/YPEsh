# YPEsh

An AI-Powered video editor that'll take in videos such as talking head ones, and will turn them into good ahh talking head videos this'll be it for the version One.


## The Vision 

So, I have an Internship, an unpaid one, there i have to edit tons of talking head videos which fry me atp, so I tried using AI tools but they want credits ahh lol, so yea why not make my own? 

## Planned Freatures

- AI captions - Add Captions using AI 
- B-Rolls - Add automatic B-rolls at relevant times
- Exportable Videos - 1080p for now

## Tech Stack

- **FrontEnd:** Next.js, TypeScript
- **Backend:** Node.js
- **AI & Video Processing:** Python
- **Version Control:** Git and Github
